KeyWord

Java has a set of keywords that are reserved words that cannot be used as variables, methods, classes, or any other identifiers 
Keyword	Description
abstract	A non-access modifier. Used for classes and methods: An abstract class cannot be used to create objects (to access it, it must be inherited from another class). An abstract method can only be used in an abstract class, and it does not have a body. The body is provided by the subclass (inherited from)
assert	For debugging
boolean	A data type that can only store true or false values
break	Breaks out of a loop or a switch block
byte	A data type that can store whole numbers from -128 and 127
case	Marks a block of code in switch statements
catch	Catches exceptions generated by try statements
char	A data type that is used to store a single character
class	Defines a class
continue	Continues to the next iteration of a loop

Identifies

Rules for Identifiers:

Can include letters (A-Z, a-z), digits (0-9), and underscores (_). Cannot start with a digit.
Cannot be a keyword.

Case-sensitive in most languages (e.g., age ≠ Age).

Examples:


1value ( invalid, starts with a digit)
count, total_sum, calculateArea (valid identifiers)
float ( invalid, it's a keyword)

Literals

Definition: Literals are fixed values directly written in the code. They represent constant values assigned to variables or used in expressions.
Types of Literals:

Integer Literals → 5, -10, 0b1010 (binary)
Floating-point Literals → 3.14, -0.5, 2.5e3 (scientific notation)
Character Literals → 'A', '1', '\n' (escape sequence)
String Literals → "Hello", "123"
Boolean Literals → true, false

Examples in Java:

int num = 10;
double pi = 3.14;
char ch = 'A';
String s = "Hi";
boolean flag = true;

Key Differences


Keywords → Fixed by the language.
Identifiers → Defined by the programmer (following rules).
Literals → Actual values in the code.
